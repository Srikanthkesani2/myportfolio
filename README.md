## ✦ About

**SRIKS.DEV** is a personal developer portfolio focused on:

- Artificial Intelligence
- Machine Learning
- Generative AI
- Full-Stack Development
- Data & Analytics
- Developer Tools
- Community Building
- Hackathons & Technical Events

The website combines a premium dark aesthetic with strong typography, subtle interactions, responsive layouts, and a clean, maintainable architecture.

The goal is to create a portfolio experience that feels like a **personal developer environment** rather than a conventional portfolio template.

---

## ⚡ Design

The visual system follows a minimal futuristic developer aesthetic:

- Near-black background
- Off-white typography
- Electric green primary accent
- Subtle cyan secondary accent
- Fine borders
- Layered depth
- Strong typography
- Responsive layouts
- Smooth transitions
- Restrained animations
- Interactive elements without unnecessary visual clutter
